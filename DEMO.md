# Демонстрация крота-бура «Копатель»

Автор ТЗ: Илья Резниченко. Разработчик: Юлия Ермолинская.

Из корня репозитория:

```sh
python demo.py
python -m unittest discover -s tests -t . -v
```

Демо показывает движение по поверхности и в грунте, проверку реки и стены, запрет воды с неизменным состоянием и замену бура на поверхности.

На проверке 28.10.2026 после исправления разработчика в PR #6 прошли все 36 тестов. TC-35 и TC-36 проверяют малые дистанции при пустом баке и износе 100.
